# Repositorio de Programación 1

Este repositorio contiene los materiales, ejercicios y ejemplos desarrollados durante el curso de programación. Está organizado por clases y temas, con ejemplos prácticos para reforzar los conceptos vistos en cada unidad.

## Objetivo del curso

El curso busca introducir y consolidar los fundamentos de la programación utilizando Python como lenguaje base, con enfoque en:

- estructuras básicas del lenguaje
- manejo de versiones con Git/GitHub
- modularización y paquetes
- programación orientada a objetos
- herencia y polimorfismo
- manejo de archivos
- tratamiento de errores

---

## Temas del curso

### Tema 1. Repaso general de estructuras básicas del lenguaje

1. Tipos de datos
2. Colecciones de datos
   - Listas
   - Tuplas
   - Diccionarios
3. Creación de procedimientos y funciones
4. Cadenas de caracteres
5. Contexto de variables
6. Environments / contextos de desarrollo
7. Setup del ambiente

### Tema 2. Mantenimiento de versiones

1. Sistemas de control de versiones
2. Concepto de repositorio
3. Ramas (branches)
4. Merge o fusión de ramas
5. Intercambio de ramas
6. Creación de repositorios en línea
   - GitHub / GitLab
   - Pull y Push
   - Merge request

### Tema 3. Módulos y paquetes

1. Concepto de programación modular
2. Importación de módulos
3. Concepto de paquete
4. Jerarquía de paquetes

### Tema 4. Programación orientada a objetos

1. Concepto de clase y objeto
2. Creación de clases y objetos
3. Métodos utilitarios de objetos
4. Relaciones entre objetos
   - Asociación
   - Composición
   - Agregación

### Tema 5. Herencia de objetos

1. Concepto de herencia
2. Tipos de herencia
3. Sobrescritura y polimorfismo
4. Principio de sustitución de Liskov
5. Patrones de diseño básicos

### Tema 7. Manejo de archivos

1. Modos de E/S
2. Streams y handles
3. Archivos de texto plano versus archivos binarios
4. Sistemas de caracteres y su influencia en el texto
5. Archivos de registros continuos
6. Archivos de registros indexados

### Tema 8. Manejo de errores

1. Concepto de excepciones
2. Captura de excepciones
3. Notificación de errores
4. Jerarquía de excepciones
5. La variable errno y sus valores

## Estructura del repositorio

El repositorio está organizado por clases y carpetas temáticas:

- `clase-1/` — repaso general de estructuras básicas
- `clase-2/` — tipos de datos, colecciones, funciones, cadenas y contexto
- `clase-3/` — trabajo práctico y Git
- `clase-4/` — ejercicios y tareas
- `clase-5/` — módulos y paquetes
- `clase-6/` — objetos y clases
- `clase-7/` — relaciones entre objetos y atributos
- `clase-8/` — propiedades, documentación y herencia
- `clase-9/` — clases abstractas, Liskov, polimorfismo
- `clase-10/` — manejo de archivos y formatos de texto
- `clase-11/` — caracteres, codificación y manejo de direcciones
- `clase-12/` — buenas prácticas y excepciones
- `clase-13/` — patrones de diseño y principios SOLID
- `clase-14/` — proyecto / ejercicio final (calculadora, librería, etc.)

## Requisitos

- Python 3.x
- Editor de código (Visual Studio Code recomendado)
- Git
- GitHub o GitLab para trabajo colaborativo y repositorios remotos

---

## Uso del repositorio

Cada carpeta representa una clase o bloque temático del curso. Se recomienda:

1. Revisar los ejemplos teóricos.
2. Ejecutar los scripts de Python.
3. Modificar los ejemplos para practicar.
4. Resolver los ejercicios de cada tema.
5. Usar Git para llevar control de cambios y sincronizar con el repositorio remoto.

## Contribución

Este repositorio se utiliza como material de apoyo para el curso. Puedes:

- practicar con los ejercicios
- crear tus propias soluciones
- documentar tus avances
- usar Git para versionar cada cambio
